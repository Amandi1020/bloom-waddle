# 🌸 Bloom & Waddle

A cute fullstack flower-collecting game with a duck companion that grows with you.

## Tech Stack
- **Frontend:** React + HTML5 Canvas + Vite
- **Backend:** Spring Boot (Java 17)
- **Database:** PostgreSQL

## Getting Started

### Prerequisites
- Node.js 18+
- Java 17+
- Maven 3.8+
- Docker Desktop

### Run locally

#### Start database
docker-compose up -d

#### Frontend
cd frontend
npm install
npm run dev

#### Backend
cd backend
mvn spring-boot:run

## Project Structure
- /frontend - React + Canvas game
- /backend  - Spring Boot REST API
